# Teoria de Elite
Site estático (HTML/CSS/JS). Rode abrindo `index.html` ou publique no GitHub Pages (Settings > Pages > branch main, pasta raiz).
- Novas aulas: edite `LESSONS` em `js/data.js` (preencha `corpo`, `resumo`, `quiz`).
- Fundos próprios: coloque `piano.jpg`, `partitura.jpg` e `biblioteca.jpg` em `assets/fundos/`.
- IA real: defina `window.TE_IA = async (pergunta) => resposta` em `js/app.js`.
